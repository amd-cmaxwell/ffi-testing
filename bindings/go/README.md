# uniffi_testing_ffi (Go)

Go bindings for the uniffi-testing math library, generated by [uniffi-bindgen-go](https://github.com/NordSecurity/uniffi-bindgen-go).

## Installation

```bash
go get github.com/amd-cmaxwell/ffi-testing/bindings/go/uniffi_testing_ffi
```

## Usage

```go
import ffi "github.com/amd-cmaxwell/ffi-testing/bindings/go/uniffi_testing_ffi"

result := ffi.Add(2, 3) // 5

roots, err := ffi.QuadraticRoots(1.0, -5.0, 6.0)
// roots.First = 2.0, roots.Second = 3.0
```

## Prerequisites

The static library `libuniffi_testing_ffi.a` is included in the repository. To rebuild from Rust source:

```bash
make build
```

This requires the [Rust toolchain](https://rustup.rs/).

## Running the demo

```bash
make demo
```
