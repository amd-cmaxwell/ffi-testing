# `make generate-python`: per-crate maturin projects

## Context

`make generate-python` needs to produce per-crate maturin Python projects under `bindings/python/` — one for each FFI crate — installable via `pip install git+https://...#subdirectory=bindings/python/<crate>`. The release workflow commits these projects (including compiled shared libraries) back to main.

## Implementation

### `generate-python` target

For each FFI crate, the target:

1. Runs `uniffi-bindgen generate --language python` against the `.so` built by `cargo build --release`
2. Copies the compiled `.so` into the project's Python package directory
3. Creates a `pyproject.toml` with maturin as the build backend, pointing to the real `Cargo.toml` via `manifest-path`
4. Creates an `__init__.py` that re-exports from the generated module

Resulting structure per crate:

```
bindings/python/uniffi-math-demo-core-ffi/
  pyproject.toml
  python/
    uniffi_math_demo_core_ffi/
      __init__.py                       (re-exports from generated module)
      uniffi_math_demo_core_ffi.py        (generated by uniffi-bindgen)
      libuniffi_math_demo_core_ffi.so     (compiled shared library)
```

`pyproject.toml` contents:

```toml
[build-system]
requires = ["maturin>=1.0,<2.0"]
build-backend = "maturin"

[project]
name = "uniffi-math-demo-core-ffi"
version = "0.1.0"
requires-python = ">=3.8"

[tool.maturin]
manifest-path = "../../../crates/ffi/core/Cargo.toml"
bindings = "uniffi"
python-source = "python"
```

### `install-python` target

Iterates over per-crate projects and runs `pip install -e` for each.

### Release workflow

The `release.yml` workflow:
1. Runs `make generate-python` on each platform (ubuntu, macOS, Windows)
2. Each platform produces its own shared library (`.so`, `.dylib`, `.dll`)
3. Artifacts are uploaded, merged, and committed back to main
4. Users install via `pip install git+https://...#subdirectory=bindings/python/<crate>`

### Files modified

- **`Makefile`** — `generate-python` and `install-python` targets
- **`.gitignore`** — remove old `_bindings/` rules
- **`.github/workflows/release.yml`** — update `build-wheels` job
- **`examples/demo.py`** — update imports for per-crate packages
